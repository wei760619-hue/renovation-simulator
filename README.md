# 裝修模擬器 Renovation Simulator

扮演室內裝修公司老闆：看懂施工圖、排好工序、選對材料，準時交屋！

## 遊戲特色
- 10 個關卡，6 種格局（公寓、新成屋、商辦、透天三層、店面＋住家、樓中樓）
- 照施工圖施作：拆除、水電插座、輕隔間、崁燈放樣
- 每關獨特機制：交屋點交、居家施工、分段交付、吊料、夜間施工、業主監工、颱風季、趕工、設計變更
- 3D 視圖（X／Y／Z 軸），完工後可在 3D 擺家具
- 工班個性、業主個性、付款拖延、工具倉庫、背景音樂

## 怎麼玩
直接用瀏覽器開啟 `index.html` 即可，手機、電腦都能玩，不需要安裝。
